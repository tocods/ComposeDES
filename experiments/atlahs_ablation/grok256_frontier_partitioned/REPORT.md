# Grok-314B-256：启动剔除后的稳态二因素消融

实验日期：2026-09-25（Asia/Shanghai）。每个配置独立运行三次。
数据集类型：LLM training；256 ranks；114,000,750 条 GOAL 操作。
计时定义：总墙钟从本次编排器启动开始；启动段到 steady-start marker（FNCS 初始化并完成初始 dispatch）；稳态墙钟 = 总墙钟 − 启动段。报告同时保留两种加速比。
本轮优化：静态任务/Batch JSON 预编译、事件日志非同步刷盘、broker 单订阅零拷贝转发、1 ms 安全 frontier 量化；横向仍保留 Active-dependency、长期 Federate 和 lease。

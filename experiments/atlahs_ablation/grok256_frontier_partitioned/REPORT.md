# Grok-314B-256：安全 Active 横向分区与纵向加速消融

实验日期：2026-09-25。每个配置独立运行三次。数据集类型：LLM training；256 ranks；114,000,750 条 GOAL 操作。

横向配置使用 8 个长期存活的计算 Federate（32 ranks/Federate），Active-dependency 与 1 ms 安全 frontier 开启。纵向配置使用 Critical-path event acceleration。异步 grant fast path 在本轮全量实验中关闭，避免未验证的跨分区提前推进；结果只包含已验证的保守协议。

计时从编排器启动开始，稳态从 steady-start marker 开始；每组保留三次原始耗时。

| 纵向 | 横向 | Federates | 稳态三次 / s | 稳态中位数 / s | 相对全关稳态 |
|---|---|---:|---|---:|---:|
| 关 | 关 | 1 | 82.332 / 83.888 / 83.144 | 83.144 | 1.000× |
| 关 | 开 | 8 | 56.778 / 57.478 / 56.702 | 56.778 | 1.464× |
| 开 | 关 | 1 | 30.018 / 30.474 / 30.122 | 30.122 | 2.760× |
| 开 | 开 | 8 | 6.891 / 6.902 / 6.885 | 6.891 | 12.066× |

横向单独优化相对全关的稳态加速为 **1.464×**；组合优化相对全关为 **12.066×**。调度轮次中位数依次为 1,117,671、115,613、1,069,305、56,244。异步 grant 数量为 0。

网络完成语义保持一致：`True`；模拟 makespan 相对跨度为 2.09e-08，10 ppm 校验：`True`。

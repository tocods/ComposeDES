# HPCG-64：JSON 预编译优化后的完整二因素消融

实验日期：2026-09-25（Asia/Shanghai）。每个配置独立运行三次。
数据集类型：HPC 稀疏计算；64 ranks；10,370,272 条 GOAL 操作；源文件 503.9 MB。
横向开启时使用 8 个长期 Federates、每个承载 8 ranks，并开启 Active-dependency、安全 frontier 和长期 lease。
本轮同时启用了编排器静态任务描述预编译、batch JSON 静态前缀缓存和事件日志免解码路径。

# HPCG-64：安全 Active 横向分区与纵向加速消融

实验日期：2026-09-25。每个配置独立运行三次。数据集类型：HPC；64 ranks；10,370,272 条 GOAL 操作。

横向配置使用 2 个长期存活的计算 Federate（32 ranks/Federate），Active-dependency 与 1 ms 安全 frontier 开启。纵向配置使用 Critical-path event acceleration。异步 grant fast path 在本轮全量实验中关闭，避免未验证的跨分区提前推进；结果只包含已验证的保守协议。

计时从编排器启动开始，稳态从 steady-start marker 开始；每组保留三次原始耗时。

| 纵向 | 横向 | Federates | 稳态三次 / s | 稳态中位数 / s | 相对全关稳态 |
|---|---|---:|---|---:|---:|
| 关 | 关 | 1 | 10.930 / 11.029 / 10.779 | 10.930 | 1.000× |
| 关 | 开 | 2 | 10.893 / 11.011 / 10.829 | 10.893 | 1.003× |
| 开 | 关 | 1 | 3.468 / 3.397 / 3.468 | 3.468 | 3.151× |
| 开 | 开 | 2 | 3.419 / 3.441 / 3.369 | 3.419 | 3.197× |

横向单独优化相对全关的稳态加速为 **1.003×**；组合优化相对全关为 **3.197×**。调度轮次中位数依次为 64,027、61,531、51,630、43,399。异步 grant 数量为 0。

网络完成语义保持一致：`True`；模拟 makespan 相对跨度为 2.92e-07，10 ppm 校验：`True`。

# 用少量端到端测量更新 GPU 准入模型

## 结论

在八个真实权重的 Qwen3‑8B 三层前缀恢复子图上，目标观测能够区分准入参数，也会改变未测配置排序。给定相同观测，后验更新未使最终选择稳定变好。自主选点时，两个准入模型都比冻结比较中的回归和通用自适应搜索更接近已测最快。随后加入的两个更简单的选点对照，在四个目标配置的成本下已经达到同等或更低的选择差距。因此这组负载支持保留静态准入预测用于缩小搜索，尚未支持把在线参数辨识或新的计算并发模型写成方法贡献。

## 标定与真实子图

A100 PCIe 40 GB。计算并发模型仍使用 ComposeDES WorkflowController 处理数据依赖。节点就绪后，按创建位置和剩余关键路径形成优先级，再判断资源准入。DMA 占用 copy engine。SM 搬运和计算根据静态核函数资源需求竞争。并发模型将实际图中各 kernel 的 grid CTA 数除以由寄存器、共享内存与 block 大小估算的设备驻留 CTA 容量，并取一个逻辑阶段内的最大值，作为该阶段的资源代理。独立观测仍决定执行工作量。不同阶段可并发准入，模型保留一个固定的计算间争用系数。这个代理在整个阶段内保持恒定，无法表示最后几波 CTA 释放资源的过程。

原模型保留单计算任务约束和固定资源估计。两个模型使用同一个 54 点共享参数网格。比较训练数据覆盖的两个级别：

| 标定集 | 图数 | 端到端配置数 | 每配置回放 |
| --- | ---: | ---: | ---: |
| 搬运链 | 8 | 120 | 12 |
| 搬运链＋并行就绪 | 24 | 298 | 12 |

新增标定用小图分别暴露两个不同规模计算任务同时就绪、同一计算与 DMA/SM 搬运共跑、搬运由不同计算生产者释放。顺序特征回归也按两套标定集训练，再用收到的目标观测更新候选分数。所有方法另外可用目标图各阶段的七次独立计时和静态图信息。

新留出来自 Transformers Qwen3‑8B 的前三个解码器层，使用原始检查点和框架 DynamicCache 生成 CPU 前缀 KV。每层执行实际 QKV、RoPE、FlashInfer attention、输出投影与 MLP，外部 CUDA Graph 保留这些数据依赖。SGLang HiCache 搬运 kernel 与 DMA 为候选搬运方式。八个负载覆盖不同前缀长度、计算规模、驻留比例、主机内存布局、预取窗口与一或两个独立请求。输入 token 序列由固定种子生成。回放层通过原框架解码器数值检查，所有候选在测试前污染旧 KV 后复验；各层 hidden state 与串行回放逐元素一致，旧 KV 与框架缓存逐元素一致。并发捕获最初暴露了共享工作区相关的数值差异，改为为各计算阶段使用独立捕获流后通过以上检查。最终报告只使用修正后的两轮。

这是一段可控制构图顺序的框架层回放。主机搬运和请求分支由实验驱动，不代表服务端连续批处理与线上请求调度，也没有测试完整 36 层模型。实际组合为每个负载 15–30 个候选，合计 225 个。A、B 两个独立进程各随机交错重复 16 次，共 7,200 次首尾测量。候选性能只使用首尾 CUDA event；没有使用 Nsight 时间线作为训练或测试特征。标定数据和模型代码的 SHA‑256 保存在冻结文件中，目标端到端数据在模型冻结后才进入评估。

## 观测如何改变未测候选

对每个参数向量 \(\theta\)，事件回放给出全部候选的预测 \(\widehat t_\theta\)。先用训练图内相对用时误差分配离线权重。对目标观测集合 \(S\)，令

\[
  e_{\theta,c}
  = (\widehat t_{\theta,c}-t_c)
      -\operatorname{mean}_{j\in S}(\widehat t_{\theta,j}-t_j).
\]

用 \(\sum_{c\in S}\log(1+(e_{\theta,c}/\sigma)^2)\) 降低不能解释目标相对耗时的参数权重，\(\sigma\) 为图独立阶段总时长尺度的 1%。共同偏移只用于把预测耗时放回与实测一致的尺度。两个以上观测可改变参数权重和未测候选排名。还保留同一模型的冻结权重对照。主动选点把参数按其预测最快的候选分组，优先测试能区分这些分组的配置，并计入潜在收益。

同点协议让所有方法看到完全相同的候选测量。自主协议让各方法选点；回归使用预测下置信界，直接搜索轮换探索未覆盖配置与搜索当前最快配置周围。预算以目标候选数计，一个候选使用进程 A 的八个偶数轮次。评估用 A 的奇数轮次或进程 B 的奇数轮次。阈值、采样规则和全部主要对照在读取目标结果前固定。

## 相同观测下的因子实验

表中是进程 B 上只在**未测候选**之间选择时，所选候选与其中实测最快者的平均差距。隔离阶段测量对所有方法一致。

| 模型 | 标定 | 4 个目标观测 | 8 个目标观测 |
| --- | --- | ---: | ---: |
| 原准入 | 搬运链 | 0.764% | 0.776% |
| 原准入 | 扩展 | 0.810% | 0.747% |
| 支持计算并发 | 搬运链 | 0.833% | 0.776% |
| 支持计算并发 | 扩展 | 0.833% | 0.776% |
| 支持计算并发、冻结参数权重 | 扩展 | 0.764% | 0.776% |
| 顺序特征回归 | 搬运链 | 1.402% | 2.227% |
| 顺序特征回归 | 扩展 | 2.172% | 2.232% |

扩展标定下的新模型在八个共同目标观测后，有效参数数从约 39.7 降至约 4.0。离线与更新后排名的合成正向检查通过。留出图上选优差距保持不变，因此本实验只支持有些参数集合被区分。相同观测下，新模型比扩展回归的平均差距小，8 个观测时按八个负载成对重采样的差距区间仍触及零。两套标定和两种准入模型没有显出稳定的相互增益。

## 同预算自主选点

数值为选中方案相对本图**全部候选**实测最快的平均差距。在冻结比较完成后，另用两个简单对照检查收益来源。先试搬运方式的搜索依次测 8 CTA、DMA、2 CTA 的搬运优先配置，再尝试当前最快搬运方式的其他顺序。按冻结先验搜索从相同首个候选开始，后续按冻结模型分数选点，并沿用共同偏移和已测值做最终选择。两者未改变已冻结的方法。

| 方法 | B 进程，4 配置 | B 进程，8 配置 | A 同进程，4 配置 | A 同进程，8 配置 |
| --- | ---: | ---: | ---: | ---: |
| 支持计算并发的主动模型 | 0.239% | 0.039% | 0.279% | 0.056% |
| 原准入主动模型 | 0.192% | 0.034% | 0.234% | 0.049% |
| 自适应分数回归 | 4.207% | 0.449% | 3.484% | 0.328% |
| 通用自适应直接搜索 | 1.141% | 1.389% | 1.271% | 1.073% |
| 搬运方式优先直接搜索，补充 | 0.059% | 0.083% | 0.103% | 0.074% |
| 按冻结模型分数搜索，补充 | 0.039% | 0.033% | 0.056% | 0.035% |

每个进程的偶数/奇数轮采用同一回放集合。给所有候选提供 A 进程测量再挑选，A 进程独立轮次的平均差距为 0.035%，跨到 B 进程为 0.033%。二者是当前负载的复测参考，样本较小。上轮 1.37% 属于不同图和不同测量条件。

从 B 的实测候选池看，最佳和次佳搬运方式之差的中位数为 1.83%，固定最佳搬运方式时搬运优先相对最佳顺序的差距中位数为 0.83%。八个负载的最快搬运方式全在 DMA、2 CTA 和 8 CTA 里。结果解释了为何先粗筛搬运方式的对照足以接近最快。补充对照是在读取本次留出结果后加入，下一轮如需正式宣称优势，应冻结这两种对照再测新工作负载。

## 复现

在本目录构建回放库并使用已具备 SGLang、FlashInfer 及 Transformers 的环境运行 GPU 端。分析端需要 NumPy，图需要 Matplotlib。设置模型路径为本地 Qwen3‑8B 检查点。

```bash
nvcc -std=c++17 -shared -Xcompiler -fPIC explicit_graph.cu -lcuda -o libexplicit_graph.so
run_dir=../../runs/mpk-a100/active-admission
mkdir -p "$run_dir"
python admission_calibrate.py --repeat 12 --output "$run_dir/active-cal.jsonl"
python active_evaluate.py "$run_dir" freeze
for session in A B; do
  python admission_framework.py --model "$model_path" --session "$session" \
    --repeat 16 --output "$run_dir/active-qwen-$session.jsonl"
done
python active_evaluate.py "$run_dir" test
python audit_active.py "$run_dir"
python ablate_active.py "$run_dir"
python plot_active.py "$run_dir"
```
